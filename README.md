# Gustavo Souza

### Cloud · Observability · FinOps · Application Security

[English](#english) · [Português](#português)

## English

I build platforms that connect cloud infrastructure, operations and security to interfaces people actually use every day. My focus is giving data context, making decisions explainable and keeping changes traceable.

The three platforms below (NOC Operation Center, Cloud Report and Shield) are **white-label**: branding, tenants, cloud accounts and integrations are configuration, so each one can be deployed for any company — MSP, cloud reseller or internal IT — and offered as a **multi-tenant SaaS**.

| Project | What it solves | |
|---|---|---|
| **[NOC Operation Center](https://github.com/gsouzacloud/noc-operation-center-portfolio)** | Operations portal: availability with expected schedules, event correlation and probable root cause, AD users and RDP sessions, SAP/HANA health, EDR, cloud audit, RDP brute-force protection, VPN, backups, client portal with MFA. | [Case study →](https://github.com/gsouzacloud/noc-operation-center-portfolio) |
| **[Cloud Report](https://github.com/gsouzacloud/cloud-report-portfolio)** | Cloud FinOps & governance: cost per account/project, idle waste and savings, quotas, backup vaults, licensing/EOL, AI cost assistant, monthly snapshots and branded reports. | [Case study →](https://github.com/gsouzacloud/cloud-report-portfolio) |
| **[Shield](https://github.com/gsouzacloud/shield-portfolio)** | WAF & application security: OWASP CRS policies, geo/IP rules, scoped exceptions, versioned publishing with rollback, redacted events, alerts and audit. | [Case study →](https://github.com/gsouzacloud/shield-portfolio) |
| **[Discovery Agent](https://github.com/gsouzacloud/discovery-agent-portfolio)** | Read-only Windows/Linux server discovery for migration planning: inventory, services, access and logon history, network, local security checks, process consumption and pending updates, turned into a multi-server HTML/PDF report with evidence and SHA-256 traceability. | [Case study →](https://github.com/gsouzacloud/discovery-agent-portfolio) |

## Português

Construo plataformas que conectam infraestrutura cloud, operação e segurança a interfaces que as pessoas usam de verdade no dia a dia. Meu foco é dar contexto aos dados, tornar decisões explicáveis e manter mudanças rastreáveis.

As três plataformas abaixo (NOC Operation Center, Cloud Report e Shield) são **white-label**: marca, clientes, contas cloud e integrações são configuração, então cada um pode ser implantado para qualquer empresa — MSP, revenda de cloud ou TI interna — e oferecido como **SaaS multi-tenant**.

| Projeto | O que resolve | |
|---|---|---|
| **[NOC Operation Center](https://github.com/gsouzacloud/noc-operation-center-portfolio)** | Portal de operação: disponibilidade com agendas esperadas, correlação de eventos e causa provável, usuários AD e sessões RDP, saúde SAP/HANA, EDR, auditoria da nuvem, proteção contra força bruta RDP, VPN, backups, portal do cliente com MFA. | [Estudo do projeto →](https://github.com/gsouzacloud/noc-operation-center-portfolio/blob/main/README.pt-BR.md) |
| **[Cloud Report](https://github.com/gsouzacloud/cloud-report-portfolio)** | FinOps e governança cloud: custo por conta/projeto, desperdício ocioso e economia, quotas, vaults de backup, licenciamento/fim de suporte, assistente de custos com IA, snapshots mensais e relatórios com papel timbrado. | [Estudo do projeto →](https://github.com/gsouzacloud/cloud-report-portfolio/blob/main/README.pt-BR.md) |
| **[Shield](https://github.com/gsouzacloud/shield-portfolio)** | WAF e segurança de aplicações: políticas OWASP CRS, regras por país/IP, exceções delimitadas, publicação versionada com rollback, eventos redigidos, alertas e auditoria. | [Estudo do projeto →](https://github.com/gsouzacloud/shield-portfolio/blob/main/README.pt-BR.md) |
| **[Discovery Agent](https://github.com/gsouzacloud/discovery-agent-portfolio)** | Descoberta somente leitura de servidores Windows/Linux para planejar migrações: inventário, serviços, histórico de acessos e logons, rede, verificações locais de segurança, consumo por processo e atualizações pendentes, num relatório HTML/PDF de vários servidores com evidências e rastreabilidade SHA-256. | [Estudo do projeto →](https://github.com/gsouzacloud/discovery-agent-portfolio/blob/main/README.pt-BR.md) |

As imagens são interfaces reais de produção, com nomes de clientes, hosts, IPs, usuários e valores anonimizados; as do Discovery Agent vêm das coletas fictícias de demonstração. Código operacional, credenciais e dados de clientes ficam privados.

**Com o que trabalho:** arquitetura e integração cloud (Huawei Cloud e conectores multi-cloud) · observabilidade e monitoramento (Zabbix, coletores próprios, PowerShell) · FinOps e governança · ambientes SAP Business One / HANA · Windows Server, Active Directory, RDS · Linux · segurança de aplicações (Nginx, ModSecurity, OWASP CRS) · React, TypeScript, Node.js, PHP, Python.
